# erp-payment

组件 `erp/payment`（收付款：收款单、付款申请与执行、资金调拨与科目收付、银行对账）的仓库。按终局设计从零开始（D59），版本从 `3.0.0` 起（A110）。

设计依据：装配项目 [be-assembly-standard](https://github.com/brickKit/be-assembly-standard) 的边界卡 `docs/zh/07-components/erp-finance.md`（`erp/payment` 一节）、决定 D47 与业务流程 `docs/zh/08-flows/order-to-cash.md`、`docs/zh/08-flows/procure-to-pay.md`。代码随重建逐步加入。
